# W00 Bootstrap

W00 is the first formal governed wave. It is `READY`, not `COMPLETED`.

## Proven prerequisites

- Public Content Factory repository initialized (not empty).
- Canonical project definition imported.
- OpenSpec `1.6.0` installed.
- Cursor and Codex OpenSpec integrations generated.

## Scope W00 establishes

Nx, Angular 22, PrimeNG, PrimeIcons, light/dark/system themes, PWA, NestJS Fastify,
Prisma/PostgreSQL, FFmpeg worker, Docker Compose, OpenSpec, Cursor/Codex rules, canonical documents,
context automation, GitHub Actions, testing, environment templates, health checks, and safe
deployment foundations.

## Candidate artifacts

Governance docs, agent rules, context scripts, and related files already in the repository are
pre-existing candidate implementation for `W00-S01`. They must be adopted, reviewed, corrected,
verified, synchronized, and archived through
`CHG-W00-S01-repository-governance-and-openspec-foundation`. No User Story or slice is completed by
bootstrap presence alone.

During W00, exact package versions must be verified against current official documentation, pinned,
and recorded in W00 evidence.
